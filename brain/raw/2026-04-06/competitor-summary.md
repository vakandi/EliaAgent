## 5 Differenciateurs Clés pour [[../../wiki/businesses/Bene2Luxe|Bene2Luxe]]

### 1. Authentification Garantie
SneakShop a une fiabilité "douteuse" selon FranceVerif. Nous, on peut insister sur le contrôle qualité 1.1.
- **Comment utiliser dans les [[../../wiki/concepts/Ads-Funnel|Ads]]**: "Chaque paire vérifiée avant envoi" / "Sneakers kontrolées, pas de surprise"

### 2. Photos Professionnelles
Règle [[../../wiki/businesses/Bene2Luxe|Bene2Luxe]]: photos pros AVANT listing. SneakShop utilise des photos génériques.
- **Comment utiliser dans les [[../../wiki/concepts/Ads-Funnel|Ads]]**: "Photos reales, pas de filtre" / Carousel avant/après sur [[../../wiki/businesses/TikTok-YouTube-Auto|TikTok]]

### 3. Service Client Français < 1h
Réponse rapide sur [[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]] [[../../wiki/businesses/B2LUXE-BUSINESS|Business]]. Avantage humain vs site impersonnel.
- **Comment utiliser dans les [[../../wiki/concepts/Ads-Funnel|Ads]]**: "Un conseiller réel, pas un bot" / "On répond en 30min max"

### 4. [[../../wiki/concepts/Pricing|Prix]] Direct Supplier
Pas d'intermédiaires = marges meilleures + [[../../wiki/concepts/Pricing|Prix]] compétitifs même avec offre -25%.
- **Comment utiliser dans les [[../../wiki/concepts/Ads-Funnel|Ads]]**: "[[../../wiki/concepts/Pricing|Prix]] usine, pas de mark-[[../../wiki/concepts/Prompt-Engineering|UP]]" / "Same qualité, moins cher"

### 5. Programme Fidélité (à créer)
SneakShop fait -25% sur 2eme paire. Nous on peut faire mieux avec cashback + points.
- **Comment utiliser dans les [[../../wiki/concepts/Ads-Funnel|Ads]]**: "Achète aujourd'hui, next paire -30%" / "Tu reviens parce que ça vaut le coup"

## Actions Prioritaires

### Action 1: Lancer [[../../wiki/channels/Snapchat|Snapchat]] [[../../wiki/concepts/Ads-Funnel|Ads]] IMMÉDIATEMENT
**Pourquoi**: SneakShop génère du trafic via [[../../wiki/channels/Snapchat|Snapchat]] (UTM detecté). C'est le moment.
**Comment**: Budget test 50€/jour pendant 7 jours, mesurer CPC et ROAS.

### Action 2: Accumuler Reviews 4.5+ sur [[../../wiki/channels/Google|Google]]/Trustpilot
**Pourquoi**: SneakShop stagne à 3.4, on peut faire mieux et convertir plus.
**Comment**: Demander reviews après chaque vente avec [[../../wiki/channels/Telegram|Message]] [[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]] personnalisé.

### Action 3: Créer Programme Fidélité Simple
**Pourquoi**: Competitiveness vs leur offre -25%. On peut faire -30% avec points.
**Comment**: Système simple: 1€ = 1 point, 100 points = -10€ sur prochaine commande.
