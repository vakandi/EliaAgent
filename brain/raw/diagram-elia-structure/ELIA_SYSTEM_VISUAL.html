🎯 Points Clés pour Sebbon

  • 📋 AGENTS.md GLOBAL: Chaque instance OpenCode charge ~/.config/opencode/AGENTS.md en premier - c'est ce fichier qui définit la personnalité d'Elia
  • 🔄 INSTANCE SPÉCIFIQUE: Chaque dossier peut avoir son propre AGENTS.md qui override le global (pas utilisé ici)
  • ⏰ CRON JOB: macOS Cron exécute le wrapper toutes les 30 minutes → lance OpenCode avec le dossier EliaAI
  • 🧠 MÉMOIRE: MEMORY.md conserve le contexte entre les executions - Elia "se souvient" des conversations passées
  • 🔌 MCP SERVERS: OpenCode utilise des "Model Context Protocol" servers pour WhatsApp, Telegram, Discord, Jira, SSH - tout est automatisé
