## 1. [[../../wiki/channels/Google|Google]] [[../../wiki/businesses/B2LUXE-BUSINESS|Business]] Profile (GBP)

### Pourquoi [[../../wiki/channels/Google|Google]] Reviews ?
- Visibilité locale gratuite
- Apparaît dans les recherches [[../../wiki/channels/Google|Google]] et [[../../wiki/channels/Google|Google]] Maps
- Preuve sociale visible publiquement

### Étapes de configuration

#### 1.1 Créer/Claim le profil [[../../wiki/channels/Google|Google]] [[../../wiki/businesses/B2LUXE-BUSINESS|Business]]

1. **Aller sur**: [[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://[[../../wiki/businesses/B2LUXE-BUSINESS|Business]].[[../../wiki/channels/Google|Google]].com
2. **Cliquez**: "Gérez maintenant" ou "Claim this [[../../wiki/businesses/B2LUXE-BUSINESS|Business]]"
3. **Rechercher**: "[[../../wiki/businesses/Bene2Luxe|Bene2Luxe]]" ou le nom de votre entreprise
4. **Si existant**: Cliquer "Propriétaire" et revendiquer
5. **Si nouveau**: Créer nouveau profil

#### 1.2 Informations à remplir

```
Nom: [[../../wiki/businesses/Bene2Luxe|Bene2Luxe]]
Adresse: [Adresse physique ou zone de livraison principale]
Téléphone: +33 [votre numéro]
Catégorie principale: Magasin de vêtements en ligne
Catégories secondaires: Luxe, Mode, Vêtements hommes/femmes
Zone de service: France, [[../../wiki/concepts/Location-Targeting#switzerland|Switzerland]]
Heures d'ouverture: 9h-20h (ou vos heures)
Site web: [[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://[[../../wiki/businesses/Bene2Luxe|Bene2Luxe]].com
```

#### 1.3 Optimisation du profil

- **Photos**: Ajouter photos de produits, entrepôt, packaging
- **Description**: "[[../../wiki/businesses/Bene2Luxe|Bene2Luxe]] - Vêtements luxe qualité 1.1. Livraison France & Suisse"
- **Questions-réponses**: Prévoir les questions fréquentes

### Demander des avis [[../../wiki/channels/Google|Google]]

**Méthode 1 - Lien direct**:
```
[[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://search.[[../../wiki/channels/Google|Google]].com/[[../../wiki/systems/Docker-Servers|Local]]/writereview?placeid=[VOTRE_PLACE_ID]
```

**Méthode 2 - Via [[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]] après livraison**:
```
"Merci pour votre commande ! 🌟
Si vous êtes satisfait de votre achat, serait-il possible de laisser un avis [[../../wiki/channels/Google|Google]] ? Cela nous aide beaucoup !
🔗 [LIEN_AVIS]

Merci infiniment ! 💫"
```

**Méthode 3 - Email de suivi**:
Envoyer un email 48h après livraison avec demande d'avis.

## 2. Trustpilot

### Pourquoi Trustpilot ?
- Plateforme d'avis internationale reconnue
- Apparaît dans les résultats [[../../wiki/channels/Google|Google]]
- Intégration possible avec emails transactionnels

### Étapes de configuration

#### 2.1 Créer un compte [[../../wiki/businesses/B2LUXE-BUSINESS|Business]]

1. **Aller sur**: [[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://[[../../wiki/businesses/B2LUXE-BUSINESS|Business]].trustpilot.com
2. **S'inscrire**: Email professionnel
3. **Company name**: [[../../wiki/businesses/Bene2Luxe|Bene2Luxe]]
4. **Website**: [[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://[[../../wiki/businesses/Bene2Luxe|Bene2Luxe]].com

#### 2.2 Plan gratuit (Free)

Le plan gratuit permet:
- 1 profil entreprise
- Demander des avis clients
- Répondre aux avis
- Widgets basiques

#### 2.3 Intégration recommandée

**Option A - Email manuel**:
```
Objet: Votre avis nous aide ! ⭐

Bonjour [PRÉNOM],

Merci pour votre commande chez [[../../wiki/businesses/Bene2Luxe|Bene2Luxe]] !

Si vous êtes satisfait de votre expérience, serait-il possible de laisser un avis sur Trustpilot ?
🔗 [[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://www.trustpilot.com/review/[[../../wiki/businesses/Bene2Luxe|Bene2Luxe]].com

Votre retour nous aide à améliorer notre service.

Merci ! 🙏
L'équipe [[../../wiki/businesses/Bene2Luxe|Bene2Luxe]]
```

**Option B - Intégration automatisée** (si disponible):
- Intégrer Trustpilot dans le流程 de commande
- Automatiser l'envoi après livraison

### Best Practices Trustpilot

1. **Demander activement** - Les clients satisfaits ne laissent pas spontanément
2. **Timing idéal** - 48h après réception du colis
3. **Personnaliser** - Mentionner le prénom du client
4. **Suivre** - Remercier les avis positifs
5. **Répondre** à TOUS les avis (positifs et négatifs)
