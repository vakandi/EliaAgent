### [[../../wiki/channels/Telegram|Telegram]] Approvals (Inline Buttons)

For high-stakes actions, request approval via [[../../wiki/channels/Telegram|Telegram]] inline buttons.

High-stakes actions include:
- Sending a [[../../wiki/concepts/File-Management|File]] / confidential info to an [[../../wiki/concepts/Prompt-Engineering|IMPORTANT]] person
- Contract/legal decisions when uncertain (entity selection: Wyoming LLC vs Montana LLC, pricing constraints, clauses)
- Notifying partners (e.g., [[../../wiki/people/Thomas-Cogne|Thomas]]) about sensitive supplier negotiations

Approval [[../../wiki/tools/Index|TOOLS]] ([[../../wiki/channels/Telegram|Telegram]] [[../../wiki/[[../../wiki/tools/Index|TOOLS]]/MCP-[[../../wiki/tools/Index|TOOLS]]|MCP]]):
- `telegram_send_approval_request(chat_id?: string, text: string, request_id?: string, keyboard?: Array<Array<{text:string, callback_data:string}>>)`
- `telegram_get_approval_responses(only_request_id?: string, limit?: number)`
- `telegram_finalize_approval(chat_id: string, message_id: number, selected_text: string)`

Mandatory workflow:
1) Send approval request with buttons.
2) Poll for responses and parse the selected choice.
3) Freeze buttons right away (replace keyboard with a single "Selected" button) so only one outcome is captured.

Waiting rule (hard gate):
- Approval is a hard gate: do not perform the high-stakes action until a choice is received.
- Poll `telegram_get_approval_responses(only_request_id: ...)` periodically while waiting.

Timeouts:
- Poll cadence: every 5-15 seconds.
- After 2 minutes without response: send ONE reminder (no spam).
- After 10 minutes without response: treat as blocked and continue with other tasks.

Sub-agents and approvals:
- Do not delegate approval-dependent work to sub-agents until approval is received.
- If a sub-agent reaches an approval gate mid-[[../../wiki/concepts/AI-Automation#tasks|Task]], it must pause that branch and [[../../wiki/docs/Sessions|Report]] it as blocked.
- Other independent work (safe / unrelated) may continue in parallel.

Default buttons:
- `✅ Accept` / `❌ Reject` / `✍️ Elaborate`

Custom choice questions (allowed):
- You may use custom buttons like `A` and `B`.
- You MUST include the full options in the message text, e.g.:
  - A = Use Wyoming LLC
  - B = Use Montana LLC

Use these [[../../wiki/tools/Index|TOOLS]] for all [[../../wiki/channels/Telegram|Telegram]] operations:

1. **`telegram_get_personal_dms_and_groups(limit: number)`**
   - Retrieves [[../../wiki/concepts/Search|List]] of personal DMs and groups
   - Returns: dialogs with unread counts, last messages, chat types
   - Use for: monitoring new messages, checking unread counts

1b. **`telegram_get_personal_dms_only(limit: number)`**
   - Retrieves ONLY personal direct messages (DMs)
   - Excludes: channels and groups (prevents crypto/spam noise)
   - Use for: primary signal collection at the start of each [[../../wiki/[[../../wiki/HOME|Docs]]/Sessions|Run]]

2. **`telegram_get_mentions_of_me(limit: number)`**
   - Retrieves messages where the authenticated user was mentioned
   - Returns: mentions with chat info, message text, links
   - Use for: tracking mentions across groups/channels

3. **`telegram_send_msg_to_default_group(message: string, audio_file_path?: string, audio_caption?: string)`**
   - Sends a message to the default [[../../wiki/docs/Sessions|Report]] group (uses `TG_CHAT_ID`)
   - Use for: [[../../wiki/concepts/AI-Automation#tasks|Task]] reports, daily summaries, status updates

3. **`telegram_send_msg_to_group(group_id: string, message: string)`**
   - Sends a message to a [[../../wiki/channels/Telegram|Telegram]] group or channel
   - **Default group for reports**: `TG_CHAT_ID` (group name "[[../../wiki/people/Elia|Elia]] IA")
   - Use for: [[../../wiki/concepts/AI-Automation#tasks|Task]] reports, daily summaries, status updates
   - **Requires approval**: Yes (for non-automated reports)

4. **`telegram_send_msg_to_dm(user_id: string, message: string)`**
   - Sends a direct message to a user
   - User ID can be: numeric ID, username (e.g., `@username`), or [[../../wiki/businesses/Bene2Luxe#account|Account]] ID
   - Use for: urgent alerts, direct notifications to owner/associates
   - **Requires approval**: Yes (always)

5. **`telegram_resolve_contact(query: string, limit?: number, max_results?: number)`**
   - Resolves a DM contact by searching recent dialogs (best-effort)
   - Use for: mapping a human name/username to a usable `user_id` before sending a DM
