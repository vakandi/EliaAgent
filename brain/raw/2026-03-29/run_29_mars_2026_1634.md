## 🔍 ACCFORGE BUG INVESTIGATION

### Bug [[../../wiki/docs/Sessions|Report]] (from DegenJuice - [[../../wiki/channels/Discord-EliaWorkSpace|Discord]])
> "Deposits work but return link is wrong (links to socialmedia.store) and money doesn't get credited to accounts"

### Root Cause Identified

**Location:** `/[[../../wiki/people/Elia|Users]]/vakandi/Documents/AccForge/backend/services/core/payment_service.py`

**Lines 601, 610, 621:**
```[[../../wiki/[[../../wiki/skills/Index|SKILLS]]/Python-Scripting|Python]]
# [[../../wiki/businesses/Bene2Luxe#stripe|Stripe]] default
"return_url": getattr(app.state, "STRIPE_RETURN_URL", os.getenv("STRIPE_RETURN_URL", "[[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://socialmediatraining.store/[[../../wiki/businesses/Bene2Luxe#payments|Payment]]/success")),

# PAYPAL default  
"return_url": getattr(app.state, "PAYPAL_RETURN_URL", os.getenv("PAYPAL_RETURN_URL", "[[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://socialmediatraining.store/[[../../wiki/businesses/Bene2Luxe#payments|Payment]]/success")),

# FREEKASSA default
"return_url": getattr(app.state, "FREEKASSA_RETURN_URL", None) or os.getenv("FREEKASSA_RETURN_URL", "[[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://socialmediatraining.store/[[../../wiki/businesses/Bene2Luxe#payments|Payment]]/success"),
```

**Issue:** The return URLs are hardcoded to `socialmediatraining.store` as fallback defaults instead of the correct store domain.

**Solution:** These [[../../wiki/businesses/Bene2Luxe#payments|Payment]] providers need to receive the correct `return_url` from the frontend checkout request, OR the environment variables need to be set to the correct domain (e.g., `[[../../wiki/topics/Infrastructure-Timeline|HTTPS]]://accforge.io` or the actual store making the request).

### Credit Issue
The "money doesn't get credited" issue likely needs investigation in the [[../../wiki/businesses/Bene2Luxe#payments|Payment]] callback handlers (`routers/payments_*.py`).
