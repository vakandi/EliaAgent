**Always say**: "Downloading and transcribing NOW"

**Workflow:**

1. **Télécharger les vocaux:**
   - [[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]]: `[[../../wiki/[[../../wiki/tools/Index|TOOLS]]/MCP-[[../../wiki/tools/Index|TOOLS]]|MCP]]-cli call [[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]] download_media '{"message_id":"<id>","chat_jid":"<jid>"}'`

   - [[../../wiki/channels/Telegram|Telegram]]: récupérer le fichier audio via l’[[../../wiki/concepts/API-Integration|API]] puis utiliser le chemin local.

2. **Transcrire avec Whisper (toujours large-v3, français):**
   ```bash
   whisper /path/to/audio.ogg --model large-v3 --language French --[[../../wiki/concepts/AI-Automation#tasks|Task]] transcribe
   ```
   Ou depuis le dossier store:
   ```bash
   cd /Users/vakandi/Documents/mcps_server/[[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]]-[[../../wiki/[[../../wiki/tools/Index|TOOLS]]/MCP-[[../../wiki/tools/Index|TOOLS]]|MCP]]/[[../../wiki/channels/WhatsApp-B2LUXE|WhatsApp]]-bridge/store/<chat_jid>/
   whisper audio_<nom>.ogg --model large-v3 --language French --[[../../wiki/concepts/AI-Automation#tasks|Task]] transcribe
   ```

3. **Paramètres obligatoires:**
   - `--model large-v3` : Toujours utiliser le grand modèle pour une transcription française précise (pas base ni medium).
   - `--language French` : Toujours français.
