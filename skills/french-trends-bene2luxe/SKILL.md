# French Trends Skill - Bene2Luxe

## Overview

This skill enables tracking and leveraging French youth culture, lifestyle trends, reality TV shows, and cultural moments for Bene2Luxe luxury fashion marketing on TikTok and Instagram Reels.

**Target Audience**: French/Swiss youth (18-35) interested in luxury fashion and aspirational lifestyle content.

**Goal**: Create content that resonates with French youth culture - making luxury fashion feel relatable, trendy, and culturally connected.

## How to Use Trends

### Trend Integration Framework

1. **Identify the trend** - What are French youth talking about this week?
2. **Assess relevance** - Can it connect naturally to luxury fashion?
3. **Create the hook** - Use the trend as your TikTok/Reels opening
4. **Deliver value** - Fashion content within the trend context
5. **Add CTA** - Follow, shop link, comment prompt

### Content Examples by Trend Type

#### Reality TV Hook
```
Hook: "Si t'avais le budget de Vincent chez Les Marseillais..."
Body: "Tu porterais quoi? Voici notre sélection luxe pour cet été."
CTA: "Dis moi en commentaire!"
```
