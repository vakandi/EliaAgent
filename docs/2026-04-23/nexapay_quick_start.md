## 📋 COMMENT APPLIQUER (60 SECONDES)

### Étape 1: Ouvrir le site
👉 **URL**: https://nexapay.one

### Étape 2: Créer un compte
- Cliquer "Get Started" ou "Sign Up"
- Entrer uniquement:
  - Email: `contact@cofibou-distribution.com`
  - Mot de passe: `Wael123!` (ou générer)

### Étape 3: Configurer le wallet de réception
- Entrer l'adresse wallet USDC/USDT (Polygon)
- Si pas de wallet Polygon → créer sur MetaMask
- ** Réseau: Polygon (MATIC) **

### Étape 4: Intégration Bene2Luxe
- Copier l'API key NexaPay
- Ajouter au site: WooCommerce → Settings → Payments
- ou Plugin NexaPay pour WooCommerce
