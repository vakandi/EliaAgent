- "Deposits work but return link is wrong (links to socialmedia.store)"
- "Money doesn't get credited to accounts"

### Cause identifiée:
Les URLs de retour (RETURN_URL) sont codées en dur vers `socialmediatraining.store` au lieu de `ogboujee.com`

### Fichiers concernés:

**docker-compose.yaml:**
```yaml
STRIPE_RETURN_URL: "https://socialmediatraining.store/payment/success"
DODO_RETURN_URL: "https://paiement.socialmediatraining.store/payment/success"
FREEKASSA_RETURN_URL: "https://socialmediatraining.store/payment/success"
```

**main.py:**
- Ligne 405: `STRIPE_RETURN_URL` default
- Ligne 418: `PAYPAL_RETURN_URL` default
- Ligne 438: `FREEKASSA_RETURN_URL` default

### Solution requise:
1. Mettre à jour docker-compose.yaml avec les bonnes URLs (ogboujee.com)
