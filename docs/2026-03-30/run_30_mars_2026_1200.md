## 🐛 Bug BEN-19: Popup recherche bloque le scroll

### ❌ Cause identifiée
Le popup de recherche utilise `position: fixed` avec `overflow: hidden` sur le body, ce qui peut bloquer le scroll sur certains navigateurs/appareils.

### Code concerné
- `/app/src/components/layout/Header.tsx` (lignes 161-202)
- `/app/src/index.css` (lignes 252-254):
```css
.search-overlay-open {
  overflow: hidden !important;
  position: fixed !important;
}
```

### 🔧 Solutions possibles
1. Améliorer le CSS pour utiliser `overscroll-behavior: contain`
2. Vérifier la gestion du scroll sur iOS Safari
3. Tester sur mobile pour reproduire le problème

### Status: En attente de clarification sur quel navigateur/appareil le problème se produit.
