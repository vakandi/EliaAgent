# Entity: Ted Nelson

## Definition

Theodor Holm Nelson (born 1937) is an American philosopher, sociologist, and information theorist. He coined the terms "hypertext" (1963) and "transclusion."

## Key Attributes

- **Born**: June 17, 1937
- **Known For**: Coining "hypertext," pioneering electronic literature
- **Notable Work**: "Literary Machines" (1980)
- **Project**: Xanadu (lifelong project for universal hypertext)

## Contributions

### Coined "Hypertext" (1963)
Nelson used the term to describe text with embedded links to other documents - predating the World Wide Web by decades.

### Xanadu Project
A visionary hypertext project started in 1960 that attempted to create a universal electronic literature system with:
- Two-way links
- Visible links
- Transclusion (embedding documents within documents)

### Transclusion
The inclusion of one document or part of a document within another via a reference. Fundamentally different from web links.

## Legacy

- Influenced Tim Berners-Lee (inventor of WWW)
- Pioneered ideas that shaped the modern web
- Frustrated visionary whose ideas were ahead of their time
