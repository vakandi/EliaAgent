# Entity: Tim Berners-Lee

## Definition

Sir Timothy John Berners-Lee (born 1955) is an English computer scientist best known as the inventor of the World Wide Web.

## Key Attributes

- **Born**: June 8, 1955
- **Role**: Director of W3C (World Wide Web Consortium)
- **Notable**: First proposed the web while at CERN (1989)
- **Award**: Turing Award (2016)

## Contributions

### Invented the World Wide Web (1989)
- Proposed "Information Management: A Proposal" at CERN
- Created the first web browser and server
- Implemented the first website (info.cern.ch)
- Made the web freely available to everyone

### Core Technologies
- **HTML**: HyperText Markup Language
- **HTTP**: HyperText Transfer Protocol
- **URL**: Uniform Resource Locator

## Connection to Memex

Berners-Lee explicitly cited Vannevar Bush's Memex as inspiration:
> "The problem was how to share information between a wide variety of incompatible computer terminals"

The web is the realization of Bush's associative linking vision.
